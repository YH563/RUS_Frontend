# Logger

> 静态全局日志器，负责打印日志信息，输出到日志文件内部

## 场景文件

无

## 关键节点

无

## 功能概述

- ✅ 功能点1：超声图像显示
- ✅ 功能点2：自动记录调用者的类名
- ✅ 功能点3：控制台彩色输出（Warn 黄色、Error 红色）
- 📝 功能点4：异步文件写入（缓冲区 + 定时器，避免阻塞主线程）

> 状态标记：✅ 已完成  🚧 进行中  📝 待办  ❌ 废弃

## 对外接口

### 输出接口

#### 1. Logger.Debug

> 输出 Debug 信息

- 输入参数
  - `string message`：Debug 信息内容
  - `object context`：调用 Debug 的对象，用于格式化输出
- 输出结果
  - `void`：在控制台输出日志信息，`[时间] [级别] [类名] 消息内容`
